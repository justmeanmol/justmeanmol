# Deep Learning Practice 🚀

This repository contains my hands-on implementations and experiments with core deep learning architectures. The goal is to build a strong understanding of how different neural network models work in practice and how they are applied to real-world problems.

---

## 📌 Topics Covered

* **Artificial Neural Networks (ANN)**
* **Convolutional Neural Networks (CNN)**
* **Recurrent Neural Networks (RNN)**
* **LSTM (Long Short-Term Memory)**
* **GRU (Gated Recurrent Unit)**
* **Transformers**

* Explore model behavior, training techniques, and performance
* Build a solid foundation for advanced AI/ML applications
